# Lemon Station Gemini Worker

This Cloudflare Worker keeps the Gemini API key on the server, checks a private access code, limits requests to eight per minute per access code, validates request sizes, and permits browser requests only from the configured site origins. Cloudflare's simple rate limiter is approximate and scoped per Cloudflare location.

## Deploy it

1. Install Node.js, then create a Gemini API key in [Google AI Studio](https://aistudio.google.com/app/apikey). Review Google's current pricing and usage limits for your account.
2. In a terminal, open this `ai-worker` folder and authenticate with Cloudflare:

   ```sh
   npx wrangler login
   ```

3. Generate a private access code:

   ```sh
   openssl rand -hex 32
   ```

   Keep the generated value private. Lemon Station will ask for it after deployment.

4. Add both values as Cloudflare Worker secrets. Wrangler prompts for each value:

   ```sh
   npx wrangler secret put GEMINI_API_KEY
   npx wrangler secret put LEMON_AI_ACCESS_TOKEN
   ```

5. Deploy the Worker:

   ```sh
   npx wrangler deploy
   ```

6. Copy the `https://…workers.dev` URL shown by Wrangler. In Lemon Station, open **Lemon AI**, paste the Worker URL and the same private access code, then choose **Connect**.

The default allowed origins cover `https://lemonstation.app`, its `www` alias, the earlier GitHub Pages URL, and the local preview on port 8785. If you publish another domain or preview on another port, add its exact origin (scheme, hostname, and port, with no trailing slash) to `ALLOWED_ORIGINS` in `wrangler.jsonc`, then deploy again. Keep this list narrow. The rate-limit namespace ID in the config must be unique in your Cloudflare account; if Wrangler reports a collision, replace `6712034` with another unused numeric ID and redeploy.

## Local checks

From the Lemon Station project root:

```sh
npm run test:ai
```

The assistant sends only the recent chat messages to this Worker. Open tasks are sent only when the user explicitly enables the task-context checkbox. The app does not send notes, clipboard history, account data, or other workspace content. The private access code stays in the current browser session and is not included in account sync or backups.

The access code, exact origin list, request limits, and rate limiting reduce casual misuse but are not a substitute for monitoring. Keep the code private, monitor Gemini usage in Google AI Studio, and rotate the code/API key if you suspect exposure. The Worker does not store chat messages. Responses are generated by Gemini and can be incorrect.
