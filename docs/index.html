A few useful details

Good to know.

Is Lemon Station free?

The web app and project ZIP are available above. Some optional services—such as Gemini AI or Supabase cloud sync—need your own accounts and may have provider-specific limits or costs.

Can I browse any website inside the web app?

The website version embeds sites that allow iframe display. Some sites block embedding; use the browser’s open-in-new-tab option for those. The Electron desktop app uses an embedded browser instead.

What does Lemon AI need?

Lemon AI is optional. It needs a separately deployed Cloudflare Worker and your Gemini API key configured there. Your API key is not included in the download or sent from the page directly to Google.

Are desktop installers available?

The native desktop app currently supports macOS only, and there is no public one-click Mac installer yet. The ZIP contains project files and setup instructions, not a ready-made installer. The web app remains browser-based.
