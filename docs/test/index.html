How to set up the private Gemini connection
  1. Follow ai-worker/README.md to deploy the Worker and set your Gemini API key and private access code as Cloudflare secrets.
  2. Use a long, unique access code. Enter the Worker URL and the same code above; Lemon Station keeps the code in this browser session only.

    ☁️ Accounts & sync

    Sign in to keep your Lemon Station data in sync across devices.

    To sync across devices, set up online storage below first. Your data stays on this device until then.

    First time? Set up sync (about 5 minutes)
    1. Make a free project at Supabase. A project is your private, online storage.
    2. In your project, open SQL Editor → New query. Copy the setup below, paste it into the editor, and click Run. It is safe to run again if you already tried this.
    3. Open Project Settings → API. Copy the Project URL and Publishable key into the fields below, then choose Save project details.
    4. Enter your email and password here, then choose Create account. After that, sign in on your other devices with the same account.
    Show database setup
